# Standalone rewrite plan

## Authorized objective

Deliver Leafloom as an independently buildable OSS replacement of NEO: Svelte, strict TypeScript, Tauri, portable contracts, one author history, extensible event-driven assistance and the original author UX.

The goal began 2026-10-02 16:56:40 UTC and the user authorized twelve hours. Stop by **2026-10-03 04:55 UTC / 05:55 Europe/London**, before the 04:56:40 UTC boundary. This is an effort deadline, not permission to declare unmet acceptance complete. The root agent owns the goal and final report.

## Workstreams

| Workstream | Owner | Deliverable |
|---|---|---|
| App/composition | Root | Library, author/shelf/book workflows, Svelte presentation, commands and workspace tooling |
| Editor/reviews | Editor agent | Portable document/edit/review contracts, one PM state/history, native surfaces and proposal lifecycle |
| Host/storage | Host agent | Tauri services, scoped durable four-file saves, recovery, native identity and delivery |
| Foundations/parity | Reference agent | Guidance/ADRs, original/candidate adapters, source traceability and full acceptance gates |

## Sequence

1. Establish strict workspace builds and contract/provider boundaries.
2. Implement authoring core and actual host storage behind portable contracts.
3. Compose library and editing workflows through Svelte Views/ViewModels.
4. Port NEO acceptance in semantic groups, retaining source actions and meaningful assertions.
5. Prove data fidelity, mixed history, restart/recovery and reviewed assistance.
6. Measure long-book interaction, rendering and persistence on reproducible synthetic fixtures.
7. Run candidate browser coverage and separately enabled native host coverage.
8. Freeze final artifacts, regenerate fresh evidence and run policy/conformance/parity gates.

## Completion

All required NEO scenarios are documented, validly exercised and passed against the production candidate with fresh artifacts. Native-only cases use real host evidence. Default development and tests require no private repository or service. Build/type/UI/conformance gates pass. Remaining failures, missing ports or stale evidence keep the goal incomplete.

See `execution-ledger.md` for actual progress and blockers. No retained spike, exported interface, scaffold or partial test count substitutes for a completed author workflow.
