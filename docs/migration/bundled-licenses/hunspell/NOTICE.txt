Hunspell spellchecking engine

Leafloom checks spelling with Hunspell 1.7.3, compiled to WebAssembly and
distributed inside the npm package @farscrl/hunspell-wasm 1.0.1 (its
JavaScript wrapper is MIT-licensed; its package LICENSE is retained with
the bundled package).

On macOS, relative to Leafloom.app/Contents/Resources:
  host/node_modules/@farscrl/hunspell-wasm/dist/lib/hunspell.mjs (embedded WebAssembly engine)
  host/node_modules/@farscrl/hunspell-wasm/LICENSE
  host/licenses/hunspell/MPL-1.1.txt

Source availability

Leafloom does not modify Hunspell. The exact source compiled into the package
is Hunspell at commit c5f98152a274e25b5107101104bef632b83a0cc9:
  https://github.com/hunspell/hunspell/tree/c5f98152a274e25b5107101104bef632b83a0cc9
It is pinned as a submodule of the wrapper's repository at the release
tag @farscrl/hunspell-wasm@1.0.1:
  https://github.com/farscrl/hunspell-wasm/tree/%40farscrl/hunspell-wasm%401.0.1
The npm package itself:
  https://registry.npmjs.org/@farscrl/hunspell-wasm/-/hunspell-wasm-1.0.1.tgz
