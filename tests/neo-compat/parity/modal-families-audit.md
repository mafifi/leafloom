Generic accessibility setup is app.js:8991–9026. It derives role/modal/name only when the dialog lacks an explicit role. It moves focus inside with requestAnimationFrame unless the backdrop already owns focus. It returns focus only to a connected non-editable keyboard-origin element when closing leaves focus on the body. Mouse-origin controls and editable caret restoration follow separate source behavior.

Native import/save/image/message dialogs come from Electron and are not custom `.modal-backdrop` families. Existing import/cover/export suites exercise those host boundaries. Pop menus use role=menu and their own Arrow/Escape/Tab contract, covered by navigation/accessibility suites.
